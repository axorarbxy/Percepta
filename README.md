# Percepta
Percepta is a software-only AI sensory augmentation platform that turns our phone, earbuds, and smartwatch into a real-time "sixth sense"; translating the world around you into intelligent audio, haptic, and visual cues through hardware you already own.

## Frontend

The frontend is built with Next.js 14, the App Router, TypeScript, Tailwind CSS, Framer Motion, and Lucide icons.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site. The shared navigation, page transition, and footer live in `src/app/layout.tsx`; design tokens and reusable layout/button primitives are in `src/app/globals.css`, `tailwind.config.ts`, and `src/components/ui.tsx`.
